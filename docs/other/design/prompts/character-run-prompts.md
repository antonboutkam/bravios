# Loopframes voor Boaz, Ravi en Pixel

Gemaakt met de ingebouwde `image_gen`-tool, met `transparent_background: true`. Elke bestaande `images/platform/run.png` diende als karakterreferentie. Per karakter is één horizontaal spritevel met vier stapfasen gemaakt en daarna in vier even grote cellen gesplitst. De uiteindelijke PNG’s staan in `public_html/gameplay/characters/{boaz,ravi,pixel}/images/platform/run-1.png` tot en met `run-4.png`, elk 288 × 384 pixels met transparantie.

## Gedeelde promptinstructies

Use case: identity-preserve. Asset type: a production 2D game running animation SPRITE SHEET, four frames in a single horizontal row, transparent background. Create FOUR distinct consecutive phases of a right-facing running cycle of the SAME reference character. Entire character in each frame, equally sized, same head size, same orientation and expression, hips centered at the same x position within each of four exactly equally wide cells. Four equal cells across the image, generous transparent space between figures and around every edge, all figures aligned to one consistent ground baseline and same body scale. Legs MUST be visibly different in each frame. No cell borders, no labels, no text, no scenery, no shadows on ground. Preserve character identity and costume exactly.
