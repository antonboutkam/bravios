# Aan de slag met Bravios

[Documentatieoverzicht](../README.md)

Deze handleiding is voor eerstejaars studenten mbo niveau 4 Software Development. Je gebruikt een bestaand spel om te ontdekken hoe HTML, CSS en JavaScript samenwerken. Je hoeft de hele code nog niet te begrijpen om te beginnen. Basiskennis van bestanden, mappen en een code-editor is voldoende voor de eerste stappen.

Volg deze volgorde:

1. [Installeren](installatie/README.md): zet het project en de benodigde software klaar.
2. [Starten en uitproberen](starten.md): start de webserver en bouw je eerste level.
3. [Broncode en werking](broncode.md): ontdek welke bestanden waarvoor dienen en volg een actie door de code.

Begin voor JSON en afbeeldingen bij [gameplay](../../public_html/gameplay/README.md). De technische code staat apart in [src](../../public_html/engine/README.md).

Wil je zelf een figuur tekenen? Lees [actiefiguren met losse afbeeldingen](actiefiguren.md).

Gebruik daarna de [uitgebreide spelhandleiding](spelhandleiding.md) als je meer wilt weten over bediening, campagnes en bouwen. [Stekelsprong](stekelsprong.md) heeft ook een eigen uitleg.

## Wat ga je leren?

Je leert het project lokaal starten, het verschil tussen broncode en spelgegevens herkennen en een kleine wijziging in de browser controleren. Je leert ook gericht zoeken in een bestaande codebasis. De oude [opdrachten](../archive/opdrachten/README.md) staan voorlopig in het archief; volg voor je schoolwerk de instructies van je docent.
