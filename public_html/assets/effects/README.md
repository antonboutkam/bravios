# Beeldeffecten

Bewaar hier afbeeldingen voor visuele effecten, zoals vonken, rook en lichtflitsen. Er zijn momenteel geen losse effectafbeeldingen: de engine tekent effecten met Canvas.

Een nieuw bestand wordt niet automatisch afgespeeld. De koppeling en timing horen in `../../engine/`. Begin bij [gameplay](../../gameplay/README.md) als je een bestaand spelonderdeel wilt aanpassen.
