# Geluidseffecten

Deze map is bedoeld voor korte geluiden, zoals springen, muntjes en botsingen. De huidige geluiden worden met Web Audio opgewekt in `../../engine/app.mjs`; er zijn nog geen losse audiobestanden.

Alleen een bestand toevoegen maakt nog geen nieuw spelgeluid. Koppel het aan de juiste spelgebeurtenis en neem het mee in de offlinebuild als je audio uit bestanden gaat gebruiken. Muziek hoort in [music](../music/README.md).
