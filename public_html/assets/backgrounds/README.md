# Achtergronden en wereldkaarten

[Alle assets](../README.md)

[crazy-backgrounds.png](crazy-backgrounds.png) bevat de achtergronden voor het gekke spel. Onder [worlds/](worlds/README.md) staan de kaartafbeeldingen van [Wonderland](worlds/wonderland/README.md) en [De avonturiers](worlds/adventure/README.md).

Een afbeelding veranderen voegt geen nieuwe campagne toe. Routepunten, velddefinities en voortgang staan in de engine. Behoud bij de eerste proef de bestandsnaam en afmetingen, ververs het spel en controleer kaartknoppen, routes en achtergronduitsneden. Bouw met `npm run build` voor offlinegebruik.
