# Website van Bravios

Begin als student bij [gameplay](gameplay/README.md). Daar staan de bewerkbare JSON-bestanden en afbeeldingen, met per onderdeel een handleiding.

| Map of bestand | Bedoeling |
| --- | --- |
| [gameplay/](gameplay/README.md) | Karakters, vijanden, platforms, obstakels, power-ups en interactieve objecten |
| [assets/](assets/README.md) | Achtergronden, decor, effecten, muziek en geluiden |
| [engine/](engine/README.md) | Technische spelcode, opmaak, servers en tests |
| [index.html](index.html) | Startpagina van de website |
| `speel.html` | Gegenereerde offlineversie; opnieuw maken met `npm run build` |

Start vanuit de projectmap met `start-server.bat`, `python server/server.py`, `php server/server.php` of `npm start`. De documentroot blijft `public_html`; open daarna `http://localhost:8080`.

Zie ook de [studentenhandleiding](../docs/student/README.md).
