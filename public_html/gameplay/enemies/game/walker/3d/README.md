# 3D-model

`model.glb` is het echte, zelfstandig laadbare 3D-model. De map `previews/` toont voorkant, achterkant, links, rechts en perspectief. Open in de 3D-bouwer **Personages in 3D** voor een draaibaar voorbeeld.

Het model is een eenvoudige driedimensionale vertaling van het bestaande figuur, met materialen en een loopanimatie. Het manifest in de bovenliggende map registreert `model3d.file`. Alleen een PNG toevoegen maakt een personage of vijand niet geschikt voor 3D.

De meegeleverde modellen kunnen opnieuw worden gegenereerd met `python3 scripts/generate-3d-models.py` vanuit de projectmap. Doe dit niet na handmatige modelwijzigingen die je wilt bewaren.
